# Exercícios de Programação

Repositório destinado à organização dos exercícios de programação desenvolvidos durante o semestre da faculdade.

## Objetivo

Registrar e organizar as atividades propostas pelo professor, facilitando o estudo e a revisão dos conteúdos trabalhados em aula.

## Organização

Cada exercício está armazenado em uma pasta individual, identificada pelo nome utilizado durante o desenvolvimento no IntelliJ IDEA.

## Tecnologias e ferramentas

- Java
- IntelliJ IDEA
- GitHub

## Observações

Os exercícios foram desenvolvidos para fins acadêmicos e de aprendizado.
